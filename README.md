## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abolfazlmahdikhanii/rentify.git
cd rentify
```

Install dependencies:

```bash
npm install
```

Create `.env.local`:

```env
MONGODB_URI=

JWT_SECRET=

IMAGEKIT_PUBLIC_KEY=
IMAGEKIT_PRIVATE_KEY=
IMAGEKIT_URL_ENDPOINT=

MAIL_HOST=
MAIL_PORT=
MAIL_USER=
MAIL_PASS=
```

Run development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
